# Chemotherapy Treatment Journal Skill

Generates a professional, English-only, print-ready chemotherapy treatment journal as a PDF.
Designed to be KDP-compatible (Amazon self-publishing). 130 pages, 8.5×11 inches, with
clinical-grade symptom tracking based on UKONS triage standards, NCI PRO-CTCAE severity
scales, and Cancer Research UK treatment record structure.

## Traffic Light Severity System

Based on UKONS (UK Oncology Nursing Society) triage standards:

```
NONE  ·  MILD  ·  MODERATE  ·  SEVERE  ·  CALL MY CARE TEAM
  0        1         2           3           ⚠ RED FLAG
```

Print this key at the top of every tracking page. Cross-reference with emergency contacts page.

### Emergency Triage Thresholds

**RED — Call immediately:**
- Temperature above 37.5°C (99.5°F) or below 36°C (96.8°F)
- Uncontrolled bleeding or unusual bruising
- Severe shortness of breath
- Signs of allergic reaction (swelling, difficulty breathing, rash)
- Confusion or fainting
- Pain not relieved by medication
- Persistent vomiting (unable to keep fluids down)
- Signs of infection (shivering, rigors, even with normal temperature)

**AMBER — Call within 24 hours:**
- Mild fever (37.0–37.5°C)
- Diarrhoea (4+ episodes in 24 hours)
- Sore mouth affecting eating
- Skin rash (not severe)
- Mild bleeding/bruising
- New or worsening symptoms

**GREEN — Tell care team at next appointment:**
- Mild fatigue, mild nausea (managed with medication), taste changes, hair loss, mild constipation, mood changes

### Core Drawing Helpers
```python
from reportlab.lib.pagesizes import letter
from reportlab.lib.units import inch
from reportlab.lib.colors import HexColor
from reportlab.pdfgen import canvas

PAGE_W, PAGE_H = letter  # 612 × 792 pts
MARGIN = 0.6 * inch
CONTENT_W = PAGE_W - 2 * MARGIN

# Colors
IVORY = HexColor("#FBF7F1")
SAGE = HexColor("#8CA396")
BLUSH = HexColor("#E3B8B0")
SLATE = HexColor("#A9BFC9")
CHARCOAL = HexColor("#3F3A36")
TAUPE = HexColor("#D8D0C7")
WHITE = HexColor("#FFFFFF")

def draw_page_bg(c, color=IVORY):
    c.setFillColor(color)
    c.rect(0, 0, PAGE_W, PAGE_H, fill=1, stroke=0)

def draw_header(c, text, y, color=CHARCOAL, font_size=21, accent=None):
    c.setFont("Georgia-Bold", font_size)
    c.setFillColor(color)
    c.drawString(MARGIN, y, text)
    y -= 6
    if accent:
        c.setStrokeColor(accent)
        c.setLineWidth(1.5)
        c.line(MARGIN, y, PAGE_W - MARGIN, y)
        y -= 8
    return y - font_size

def draw_section_band(c, text, y, accent=SAGE, width=CONTENT_W):
    band_h = 22
    c.setFillColor(accent)
    c.roundRect(MARGIN, y - band_h + 4, width, band_h, 3, fill=1, stroke=0)
    c.setFillColor(WHITE)
    c.setFont("Georgia-Bold", 12)
    c.drawString(MARGIN + 8, y - band_h + 10, text)
    return y - band_h - 6

def draw_checkbox(c, label, x, y, checked=False):
    c.setStrokeColor(CHARCOAL)
    c.setLineWidth(0.8)
    c.rect(x, y - 2, 0.18*inch, 0.18*inch, fill=0, stroke=1)
    c.setFont("Georgia", 10)
    c.setFillColor(CHARCOAL)
    c.drawString(x + 0.18*inch + 4, y, label)
    return y - 0.18*inch - 4

def draw_writing_lines(c, x, y, width, count, spacing=0.4*inch):
    c.setStrokeColor(TAUPE)
    c.setLineWidth(0.4)
    for _ in range(count):
        c.line(x, y, x + width, y)
        y -= spacing
    return y
```

### Page Builder Pattern
Each page type is one function:
```python
def build_[page_type](c, [params]):
    draw_page_bg(c)
    y = PAGE_H - MARGIN
    y = draw_header(c, "Page Title", y, accent=SAGE)
    # ... draw content ...
    c.showPage()
```
